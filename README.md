# 제주 시대별 역사유적 안내

제주특별자치도 **제주역사문화 위치정보·일반정보**(공공데이터포털 API)를 시대별로 나누어 보여 주는 안내 사이트입니다.
한국어·English·中文·日本語를 지원하고, 마음에 드는 곳을 찜해서 **나만의 답사 코스**를 지도에 선으로 이어 볼 수 있습니다.

```
브라우저(index.html) → /api/places (Vercel 함수) → 공공데이터포털 API 2개 (위치정보 + 일반정보)
        └─ API를 쓸 수 없으면 → 내장된 1단계 파일 데이터로 대신 표시 ('연습 모드')
```

---

## 1. 화면 구성

사이트는 `index.html` 한 페이지입니다. 그 안에 **화면 5개**와 **상태 표시 2개**가 있습니다.

| # | 화면 | 무엇을 보여 주나 |
|---|---|---|
| 1 | **상단 바** | 언어 선택(4개 국어), 시대 버튼(전체·선사·탐라국·고려·조선·근현대·그 외, 각 개수 표시), 검색창, `찜한 곳만` 버튼, `카드 / 표` 전환 |
| 2 | **지도** | 장소 핀(시대별 색), 핀을 누르면 설명 말풍선과 찜 버튼. 일반 지도/위성 사진 전환. 검색·필터와 핀이 함께 걸러짐 |
| 3 | **나의 답사 코스** | 찜한 장소를 누른 순서대로 번호 핀과 점선으로 연결. 구간별·전체 직선거리, 순서 변경(▲▼), 가까운 순 정렬, 구글 지도 길찾기, 링크 복사 |
| 4 | **목록** | 두 가지 보기. **카드 보기**는 시대별 구역(시대 소개 + 카드: 장소명·주소·분류 근거·요약·버튼), **표 보기**는 120곳을 정렬 가능한 표로 |
| 5 | **상세 팝업** | 시대·주소·좌표·관련 자료 정보, 긴 본문(내용·목차·초록·참고문헌, 접기/펼치기), 원문·지도 링크, Google 번역 열기(한국어 외 언어) |

상태 표시
- **불러오는 중** — 데이터를 받아오는 동안 목록 자리에 안내 문구를 보여 줍니다.
- **연습 모드 배너** — API를 쓸 수 없을 때 화면 위에 노란 배너로 표시하고, 내장 데이터로 계속 보여 줍니다. (`API 다시 불러오기` 버튼 포함)

## 2. 사용자 관점 개선점 10가지

처음 방문한 사용자(관광객·학생)가 사이트를 써 본다고 가정하고 불편한 점을 정리했습니다. ✅는 이번에 구현한 항목입니다.

1. ✅ **코스 순서가 비효율적** — 찜한 순서대로만 이어져서 왔다 갔다 한다 → 가까운 곳부터 이어지도록 자동 정렬
2. ✅ **내 코스를 다른 사람과 못 나눔** — 찜 목록이 내 브라우저에만 있다 → 코스 링크 복사, 링크로 열면 같은 코스가 불러와짐
3. ✅ **실제로 가는 길을 모름** — 직선거리만 보인다 → 구글 지도 길찾기로 바로 연결
4. ✅ **찜한 곳만 모아 보기 어려움** — 120곳 중에서 찾아야 한다 → `찜한 곳만` 필터 (카드·표·지도 모두 적용)
5. ✅ **상세 본문이 너무 길다** — 수천 자가 한꺼번에 펼쳐져 읽기 부담 → 긴 본문은 접어 두고 `더 보기`
6. ⬜ **내 주변 유적을 알고 싶다** — 현재 위치 기준 가까운 순 정렬과 거리 표시
7. ⬜ **지도에서 핀이 겹쳐 눌러지지 않는다** — 가까운 핀을 묶어 보여 주는 클러스터
8. ⬜ **글자가 작고 대비가 약하다** — 글자 크기 조절, 고대비 모드
9. ⬜ **시대 흐름이 한눈에 안 보인다** — 선사→근현대를 가로 연표로 보여 주기
10. ⬜ **지역으로 찾고 싶다** — 제주시/서귀포시 필터, 검색어 자동완성과 결과 강조

## 3. API 대비

- **불러오는 중 표시**: 접속하면 먼저 "데이터를 불러오는 중입니다…"가 보이고, 받아오면 목록으로 바뀝니다. (네 언어)
- **실패하면 연습 모드**: API 호출이 실패하면(키 없음·키 오류·네트워크 오류·서버 없음 등) 1단계의 파일 데이터 120곳을 대신 보여 주고, 위쪽에 `연습 모드` 배너와 실패 원인을 표시합니다. 화면이 비거나 깨지지 않습니다.
- 이 때문에 `index.html` 을 **더블클릭해서 열어도** 연습 모드로 동작합니다.
- 확인한 경우: ① 정상 키 → 정상 모드 ② `JEJU_CULTURE_*_KEY` 가 비어 있는 서버 → 연습 모드 + 배너 ③ 파일로 직접 열기 → 연습 모드

## 4. 이번에 고친 것 / 추가한 것

**고친 것**
- API 호출 실패 시 오류 화면만 나오던 것을 **연습 모드(내장 파일 데이터)** 로 대체
- 인증키 환경변수를 `JEJU_CULTURE_INFO_KEY`, `JEJU_CULTURE_LOCATION_KEY` 두 개로 정리 (API 주소는 공개 정보라 코드에 둠)
- 상세 팝업의 긴 본문을 접어 보이도록 개선 (개선점 5)

**추가한 것**
- 연습 모드 배너와 `API 다시 불러오기` (4개 국어)
- `찜한 곳만` 필터 (개선점 4)
- 코스 **가까운 순 정렬** (개선점 1) — 시험 코스 5곳에서 107.6km → 60.3km
- **구글 지도 길찾기** 링크, 최대 11곳까지 (개선점 3)
- **코스 링크 복사** 와 링크(`#route=…`)로 코스 불러오기 (개선점 2)
- 새 문구 전체의 4개 국어 번역

**직접 확인한 것** (실제 Edge 브라우저에서 자동 시험): 불러오는 중 표시, 정상/연습 모드 전환, 찜 → 정렬 → 길찾기 주소 → 찜만 보기 → 공유 링크 불러오기 → 본문 접기/펼치기, 언어 전환 시 새 문구 번역

## 환경변수 (Vercel: Settings → Environment Variables)

| 이름 | 값 |
|---|---|
| `JEJU_CULTURE_INFO_KEY` | 제주역사문화**일반정보**(15109587) API 인증키 |
| `JEJU_CULTURE_LOCATION_KEY` | 제주역사문화**위치정보**(15109570) API 인증키 |

- 인증키는 코드에 넣지 않고 위 환경변수에서만 읽습니다. 서버 함수가 대신 호출하므로 브라우저에 노출되지 않습니다.
- API 주소는 공개 정보라서 `api/places.js` 에 들어 있습니다.
- 값을 넣은 뒤에는 **Redeploy** 해야 반영됩니다. 응답은 하루 동안 Vercel 엣지에 캐시됩니다.

## 로컬 실행

`.env.example` 을 `.env.local` 로 복사해 키를 채운 뒤 `npm run dev` → http://localhost:3000
(`.env.local` 은 Git에 올라가지 않습니다. 값을 바꾸면 서버를 껐다 켜세요.)

**키 없이 시험** (CSV를 모의 API로 사용): `.env.local` 을 아래처럼 채우고, 터미널 두 개에서 각각 실행합니다.
(`*_URL` 두 줄은 모의 서버로 바꿔 끼울 때만 쓰는 선택 항목입니다. 실제 API를 쓸 때는 넣지 마세요.)

```
JEJU_CULTURE_INFO_KEY=TESTKEY
JEJU_CULTURE_LOCATION_KEY=TESTKEY
JEJU_CULTURE_INFO_URL=http://localhost:4010/general
JEJU_CULTURE_LOCATION_URL=http://localhost:4010/location
```

```bash
npm run mock
```

```bash
npm run dev
```

## 파일 구조

- `index.html` — 화면 (`src/` 를 합쳐 만든 단일 파일)
- `api/places.js` — API 함수 (두 API를 불러 장소 번호로 합침)
- `src/template.html`, `src/eras.js`, `src/i18n.js` — 화면 원본 / 시대 분류 / 번역. 수정 후 `npm run bundle` (이름을 `build`로 하면 Vercel이 자동 빌드로 인식해 배포가 실패합니다)
- `src/legacy/data.js` — 1단계 파일 데이터. 빌드할 때 연습 모드용으로 `index.html` 에 내장됩니다
- `dev/` — 로컬 시험용 모의 API와 개발 서버

## 알아둘 점

- 시대 분류(`src/eras.js`)와 번역(`src/i18n.js`)은 `데이터 고유번호`를 기준으로 연결돼 있습니다. API에 장소가 추가되면 "그 외 장소"에 들어가며, 시대를 지정하려면 `eras.js` 에 추가하세요.
- 시대 분류와 번역은 CSV/API에 없는 정보라서 직접 정리한 참고용입니다.
- 지도는 인터넷 연결이 필요합니다. (OpenStreetMap France / Esri 타일)
